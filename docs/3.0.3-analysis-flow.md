# 3.0.3 — AI 就緒但無法開始分析

改動範圍：分析入口、人物候選選取、狀態與診斷。沿用 3.0.2 的 MediaPipe 引擎、模型、本機紀錄與核心運算。

- 不再因為尚未點選人物而無提示地停用開始按鈕。沒有影片時明確提示；有影片但沒有目標時先跑目前影格的真實人物偵測。
- 本格只偵測到一人時自動選取並提示核對。多於一人時列出有編號的縮圖，由使用者明確按「分析人物 N」。偵測數量不保證等於現場人數。
- 影片旁顯示 AI、影片解碼、選人三項狀態；進度另以浮動文字顯示。不得用 AI ready 宣稱已完成分析。
- 推論失敗會關閉失效的引擎並恢復重試按鈕；沒有骨架時不顯示分析成功。
- 提供不含原片、圖片、姓名或點位的診斷 JSON，包含版本、瀏覽器、媒體狀態及錯誤階段。
- 預設最多分析 15 秒，可調 1–60 秒；從已選目標的時間開始，不再因原片長於 60 秒直接拒絕。

驗證：tests/browser_smoke.py 使用公開照片製成的重複影格 MP4、MOV 和四格拼貼，另作 SDK／推論失敗注入。CI 通過與否以工作流程結果及 browser-results.json 為準。這不是使用者 IMG_3270.mov，也不是競走準確度或所有手機的實機驗證。
