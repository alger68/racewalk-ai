# 3.0.4 指定選手確認與保守追蹤

修正 3.0.3 將縮圖選取降成框中心，開始分析時再配對，以及追蹤只挑最近人物的問題。

## 操作
在清楚影格暫停 → 按「框選指定選手」拖曳框住整位選手，或辨識目前畫面人物 → 點縮圖 → 核對金色框／縮圖 → 按「確認這位選手」 → 按「開始鎖定分析」。單一偵測人物也必須確認。不會因未選目標而自動選最大框或第一位。

## 資料與追蹤
第一格直接採用使用者確認的骨架快照與時間，不重新猜選人物。後续格用肩髖軀幹中心、移動預測、尺度、起始衣色直方圖進行有門檻的關聯；偵測陣列的順序不是人物身分。框選區域的點位必須投影回原始影片座標，顯示座標扣除黑邊。

失聯、近似配對或軀幹重疊時停止，拒絕格不輸出目標點位或角度，且不自動重新捕捉。已取得結果可匯出。新起點需重新指定；新選取產生新片段標籤，不把旧結果重新貼上新標籤。JSON、CSV 記錄 targetId；診斷不含影片、圖片、姓名、點位或衣色資料。

## 驗證範圍與限制
36 個合成關聯測試含四人 24 種排序、720 次影格配對檢查，以及框外點選、重疊歧義、失聯鎖存、衣色不符、黑邊座標和時間不連續。瀏覽器測試在 Chromium 與手機尺寸 WebKit 跑真實模型，使用公開照片製成的 MP4／MOV 和四格拼貼，刻意指定非第一個偵測人物並核對報告座標，另測框選、重新指定、人工修點與故障注入。

這些是選取／追蹤防護的回歸測試，不是使用者實際比賽影片，不提供身分辨識或競走判讀準確度保證。相同衣著、完全遮擋、模型混接骨架仍可能誤配；需回看原片。保守暫停可能中斷原本可追蹤的片段，不能透過降低門檻就宣稱更準確。
