# 3.0.5：停止取值不再等於停止整段

## 問題與修正
3.0.4 的拒絕配對分支直接 break。重複偵測骨架、衣色遮擋等情況會讓整段分析在早期中止。3.0.5 先按肩／髖的解剖點位一致性排除近似重複觀測；不只按框重疊合併，附近不同軀幹仍分開。

確認目標後逐格使用跟隨該目標的局部裁切，點位投影回原影片座標。此時候選數不是全場人數。短暫失聯／歧義時，影格與進度繼續，該格 landmarks 與膝角為 null。連續三次核對通過才恢復；沒有插值、補造角度或無條件選最近的人。超過 0.75 秒仍無法可靠核對時，餘段繼續掃描但停止取值，需在清楚影格重新指定。

圖表與誤差带不跨過缺值連線。報告區分完整時間掃描與有效配對影格；配對通過不等同姿勢測量正確率，也不是裁判判決。

## 載入
模型使用穩定 URL、檔長與 SHA-256 驗證的 CacheStorage 快取。首載仍須下載，後續在同一瀏覽器且快取未被清除時可重用。模型下載與 WASM 初始化分開提示；儲存空間不足或私密瀏覽不應使分析崩潰。

## 驗證界線
持續保留核心、指定選手與瀏覽器互動回歸測試，新增缺值繼續掃描、三格恢復、長失聯拒絕重配、重複觀測與快取驗證。公共 CI 不包含使用者影片。真實影片在工作容器另行重現，不能用公共照片拼貼宣稱真實競走准确率。GitHub 版本仍不是原 hosted simulator 的同一份引擎。
