# 拍攝規格與現場 SOP

騰空時間只有 20–40 毫秒，**幀率決定這個專案的上限**。預算優先順序是
幀率 > 快門 > 解析度。4K@30fps 對本專案毫無用處。

## 規格

| 條件 | 建議 | 理由 |
|---|---|---|
| 幀率 | **≥ 240 fps**；120 fps 為下限 | 40 ms 的騰空在 240 fps 下有約 10 個取樣點；60 fps 只有 2–3 個 |
| 快門 | ≥ 1/1000 s | 動態模糊會糊掉腳與地面的接觸邊界，直接毀掉 IC/TO 精度 |
| 解析度 | 1080p 即可 | 把預算留給幀率與快門 |
| 感光元件 | 有預算選 global shutter | rolling shutter 會讓快速移動的腳部變形 |
| 機位 | 側向，光軸**垂直於行進方向**，高度 0.8–1.0 m，距離 5–8 m | 矢狀面才能正確量膝角 |
| 鏡頭 | 等效 50–85 mm，避免廣角 | 廣角桶形變形會扭曲角度 |
| 光線 | 戶外日光最佳；室內 ≥ 1000 lux | 1/1000 s 快門很吃光 |
| 地面參考 | 貼 1 m 間距標記帶並入鏡 | 供 homography 標定與地面線推算 |
| 背景 | 乾淨、與服裝對比明顯 | 提升足部關鍵點穩定度 |

## 三級方案

- **入門（NT$0）**：手機慢動作 240 fps @1080p + 三腳架。**建議從這裡開始。**
  需充足日光，並鎖定對焦避免漂移。
- **標準（NT$2–5 萬）**：240 fps 運動相機或無反 + 定焦鏡 + 三腳架 + 補光。
- **進階（NT$10 萬+）**：global shutter 工業相機 240–500 fps + 硬體同步雙機位
  （側向 + 斜後 45°），可三角量測，大幅降低 2D 投影誤差。

## 現場檢查清單

拍攝前：

- [ ] 相機設定確認在高幀率模式（很多機種切到慢動作會自動降解析度，要確認）
- [ ] 快門速度手動鎖定 1/1000 s 以上，不要用自動
- [ ] 對焦鎖定在賽道中線，關閉連續自動對焦
- [ ] 三腳架水平，光軸垂直於行進方向（用地面標記線目視對齊）
- [ ] 地面標記帶入鏡，且至少兩個標記同時可見
- [ ] 試拍 5 秒，用 `racewalk check` 確認幀率被正確寫入檔案

拍攝時：

- [ ] 每位選手至少拍到 4 個完整步態週期
- [ ] 選手全身入鏡，尤其雙腳不可出框
- [ ] 同一機位連續拍攝，中途不要變焦或移動

拍完後：

- [ ] 原始檔直接備份，不要用會重新編碼的方式傳輸（通訊軟體通常會壓縮並降幀）
- [ ] 記錄選手、日期、配速、場地條件

## 為什麼要鎖定快門

自動曝光在雲層飄過時會改變快門速度。快門一變慢，動態模糊就變大，
足部關鍵點的位置精度隨之改變——而系統無法從影片本身察覺這件事，
只會默默地把誤差變大的結果照常輸出。手動鎖定是唯一可靠的作法。
